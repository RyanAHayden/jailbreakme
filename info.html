About

What is this?
A one-tap jailbreak that runs from a web page. No computer, no cable, no signing.
Who made the exploit?
Calif, a security research firm (calif.io). This page is ours: we package publicly released exploits so you can run them from Safari. We're not Calif and don't speak for them.

Release

Which iOS versions?
iOS 27.0.1 at least. Calif's demo ran on iOS 27.0.1; iOS 27.2 patched most of it. The exact range is posted with the release, and the front page checks your version for you.
When can I jailbreak?
Only once a working exploit is public. Calif has demoed it but hasn't released a tool. Turn on notifications on the front page to hear the moment it drops.
Should I update iOS?
Not if you want to jailbreak: stay on the version you have.

Safety

Is that other site real?
Any site selling an iOS 27 jailbreak, or asking you to install a profile or app first, is a scam. We will never charge or ask for either.
Is it safe?
Back up first. Restoring undoes a jailbreak, but your data is your responsibility.

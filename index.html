What is this?
A one-tap jailbreak that runs from a web page. No computer, no cable, no signing.
Who made the exploit?
Calif, a security research firm. This page is ours: we package publicly released exploits so you can run them from Safari. We're not Calif and don't speak for them.
When can I jailbreak?
Only once a working exploit is public. Calif has demoed iOS 27 jailbreaks but hasn't released a tool, and iOS 27.2 patched most of it. Bookmark this page: the slider goes live if and when it can.
Is that other site real?
Any site selling an iOS 27 jailbreak, or asking you to install a profile or app first, is a scam. We will never charge or ask for either.
Which devices?
The supported range is posted with each release. This page checks your iOS version for you.
Is it safe?
Back up first. Restoring undoes a jailbreak, but your data is your responsibility.
